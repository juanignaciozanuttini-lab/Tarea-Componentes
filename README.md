# Tarjetas de presentación en ReactJS

## Descripción:

Este proyecto basicamente consiste en una página web que muestra tres tarjetas de presentación con información diferente.

## Tegnologias utilizadas:

Usé ReactJS junto a css

## Componentes

Tajeta.jsx: Define el componente Tarjeta,que luego recibe Props y las utiliza para mostrar información com el nombre,la profesión,la imagen y la descripción de cada persona

App.jsx: Importa el Tarjeta.jsx y le asigna diferentes valores a cada una de sus Props para mostrar tres tarjetas con información distinta, Tambien importa  App.css,que es el archivo que le da estilo a las tarjetas.

## Instalación

1-Clonar el repositorio desde GitHub.
2-Abrir la carpeta del proyecto en Visual Studio Code.
3-Instalar las dependencias ejecutando el siguiente comando en la terminal:

   `npm install`

## Ejecución

Para iniciar la aplicación en el entorno de desarrollo, ejecutar:

`npm run dev`

Luego, abrir en el navegador la dirección local que aparece en la terminal.
